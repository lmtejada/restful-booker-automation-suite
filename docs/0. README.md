# Documentation Map

How the docs in this folder fit together, and what order to read them in when starting a new project from this scaffold.

---

## Suggested reading order

1. **[APP-OVERVIEW.template.md](APP-OVERVIEW.template.md)** — what the app under test actually is, before anything else.
2. **[TEST-PLAN.template.md](TEST-PLAN.template.md)** — strategy, scope, and the risk register that drives what gets tested first.
3. **[TEST-FRAMEWORK.template.md](TEST-FRAMEWORK.template.md)** — how the suite itself is built: structure, conventions, tagging.
4. **[TEST-CASES.template.md](TEST-CASES.template.md)** — the actual test case definitions.

Each starts as a `.template.md` file — copy it, drop the `.template` suffix, and fill it in for the real project (see the note at the top of each file).

---

## Core docs (this folder)

Written once, revised occasionally as strategy or structure changes.

| Doc                        | What's in it                                                         |
| -------------------------- | -------------------------------------------------------------------- |
| APP-OVERVIEW.template.md   | App-under-test field guide — what it is, user roles, known quirks    |
| TEST-PLAN.template.md      | Strategy, risk register, CI/CD gating, entry/exit criteria           |
| TEST-FRAMEWORK.template.md | Folder structure, conventions, tagging, the append-only decision log |
| TEST-CASES.template.md     | Every test case (TC-XXX), grouped by module                          |

## Related (`related/`)

Living records, updated continuously as the suite actually runs — kept in their own subfolder rather than mixed in above, so this top-level folder stays scannable at a glance and each log can be updated on its own cadence without churning the core docs.

| Doc                                        | What's in it                                         |
| ------------------------------------------ | ---------------------------------------------------- |
| related/DEFECT-LOG.template.md             | Functional and accessibility defects, linked to a TC |
| related/EXPLORATORY-SESSIONS.template.md   | Unscripted exploratory session logs                  |
| related/TEST-EXECUTION-SUMMARY.template.md | Pass/fail counts per run, appended over time         |

---

Repo-level setup, scripts, and CI documentation lives in [../README.md](../README.md), not here.
